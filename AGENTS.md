# Filmber Sync for Jellyfin — project instructions

- `../filmber` — связанный backend-репозиторий для локальной разработки.
- Контракт API подтверждается по текущему коду Filmber, его схеме и тестам.
- Изменения API должны сопровождаться синхронными изменениями документации и
  тестов в обоих репозиториях.
- Репозитории не связываются локальными импортами, symlink или submodule.
- Runtime-связь с Filmber выполняется только исходящими HTTPS-запросами.
- Нельзя копировать секреты или `.env` из Filmber.
- Нельзя логировать токены, пароли, пути медиафайлов или приватные адреса Jellyfin.
- Публикация, GitHub remote, push и релизы выполняются только по явному запросу.
- Точная совместимость заявляется только для фактически проверенных версий Jellyfin.
