# Установка Filmber Sync for Jellyfin

## Что понадобится

- Jellyfin Server `10.11.8`;
- права администратора Jellyfin;
- аккаунт Filmber;
- исходящее HTTPS-соединение сервера с `https://filmber.online`;
- TMDB ID в метаданных фильмов и сериалов Jellyfin.

Без точного TMDB ID плагин не пытается угадывать тайтл по названию.

## 1. Добавьте репозиторий плагина

1. Откройте Jellyfin → «Панель управления → Плагины → Репозитории».
2. Нажмите добавление репозитория.
3. Укажите любое понятное имя, например `Filmber`.
4. Вставьте URL:

```text
https://github.com/dmitrijovsjanik/filmber-jellyfin-plugin/releases/latest/download/manifest.json
```

5. Сохраните репозиторий.
6. Откройте «Каталог», найдите Filmber Sync и установите плагин.
7. Перезапустите Jellyfin.

Альтернативный вариант — скачать ZIP из
[GitHub Releases](https://github.com/dmitrijovsjanik/filmber-jellyfin-plugin/releases),
распаковать DLL в папку плагинов Jellyfin и перезапустить сервер.

## 2. Подключите пользователя

1. Откройте «Панель управления → Плагины → Filmber Sync».
2. Нажмите «Подключить» напротив нужного пользователя Jellyfin.
3. Плагин покажет одноразовый шестизначный код.
4. Откройте Filmber → «Профиль → Настройки → Jellyfin».
5. Нажмите «Ввести код Jellyfin», введите код и проверьте имя пользователя.
6. Нажмите «Разрешить».

Можно также нажать «Открыть Filmber» на странице плагина: код будет передан в
ссылке автоматически.

Токен создавать и копировать не нужно. После подтверждения Filmber выдаёт
отдельную сессию именно для этого пользователя Jellyfin, а плагин сохраняет её
автоматически.

## 3. Подключите остальных пользователей

Если Jellyfin используют несколько человек, повторите подключение для каждого
пользователя. Один пользователь Jellyfin связан только с одним аккаунтом
Filmber.

## Отключение

Подключение можно отозвать с любой стороны:

- в Jellyfin: «Панель управления → Плагины → Filmber Sync → Отключить»;
- в Filmber: «Профиль → Настройки → Jellyfin → Отключить».

При отключении из Jellyfin плагин сначала отзывает сессию в Filmber и только
после успешного ответа удаляет локальную привязку.

## Данные и безопасность

- плагин отправляет TMDB ID, тип события, прогресс, сезон и эпизод;
- пути к медиафайлам, адрес Jellyfin и пароль пользователя не отправляются;
- токен Filmber хранится в XML-конфигурации плагина на сервере Jellyfin;
- токен не показывается в Dashboard и не записывается в логи;
- доступ к файлам конфигурации должен быть ограничен системным пользователем,
  под которым работает Jellyfin.

## Если синхронизация не работает

Проверьте:

1. включена ли синхронизация на странице плагина;
2. не помечено ли подключение как истёкшее;
3. есть ли у фильма или сериала TMDB ID;
4. может ли сервер открыть `https://filmber.online` по HTTPS;
5. загружен ли плагин после перезапуска Jellyfin.
