Filmber Sync for Jellyfin

Watched movies, episodes, and playback progress are saved to Filmber automatically from every Jellyfin client.

How it works
  1. Choose the Jellyfin user you want to connect.
  2. Open Filmber → Profile → Settings → Jellyfin and enter the one-time code.
  3. Confirm the connection. No token needs to be created or copied.
Only explicitly connected Jellyfin users are synchronized.
Advanced settings
Keep the default address unless you run your own Filmber environment.

Jellyfin users

Each Jellyfin user connects to their own Filmber account.
