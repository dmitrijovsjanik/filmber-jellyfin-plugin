# Filmber Sync for Jellyfin

Плагин сохраняет новые события просмотра из Jellyfin в ваш аккаунт Filmber:

- прогресс фильма или серии;
- просмотренные фильмы;
- просмотренные эпизоды.

Плагин устанавливается на сервер Jellyfin и сам отправляет данные в
`filmber.online` по HTTPS. Открывать Jellyfin в интернет, настраивать webhook,
копировать пароль, API key или токен не нужно.

Важно:

- синхронизация работает только в направлении **Jellyfin → Filmber**;
- существующая история Jellyfin при установке не импортируется;
- новые просмотры начинают сохраняться после подключения пользователя;
- каждый пользователь Jellyfin подключается к своему аккаунту Filmber.

## Что понадобится

- Jellyfin Server `10.11.8`;
- права администратора Jellyfin;
- аккаунт Filmber;
- доступ сервера Jellyfin к `https://filmber.online`.

TMDB ID обычно добавляется к фильмам и сериалам самим поставщиком метаданных
Jellyfin. Вручную указывать его не требуется. Если у тайтла нет TMDB ID, плагин
не будет угадывать его только по названию.

## 1. Добавьте репозиторий плагина

1. Откройте Jellyfin → «Панель управления → Плагины → Репозитории».
2. Нажмите кнопку добавления репозитория.
3. В поле имени укажите `Filmber`.
4. Вставьте URL:

```text
https://github.com/dmitrijovsjanik/filmber-jellyfin-plugin/releases/latest/download/manifest.json
```

5. Сохраните репозиторий.

## 2. Установите плагин

1. Откройте вкладку «Каталог».
2. Найдите `Filmber Sync`.
3. Нажмите «Установить».
4. Перезапустите Jellyfin.

После перезапуска Filmber Sync появится среди установленных плагинов.

## 3. Подключите пользователя Jellyfin

1. Откройте «Панель управления → Плагины → Мои плагины → Filmber Sync».
2. Напротив нужного пользователя нажмите «Подключить».
3. Плагин покажет одноразовый 6-символьный код.
4. Откройте Filmber → «Профиль → Настройки → Jellyfin».
5. Нажмите «Ввести код Jellyfin».
6. Введите код, проверьте имя пользователя и нажмите «Разрешить».

Можно нажать «Открыть Filmber» на странице плагина — код уже будет добавлен в
ссылку.

## 4. Включите синхронизацию

Вернитесь на страницу Filmber Sync в Jellyfin:

1. Включите «Синхронизацию».
2. Оставьте адрес Filmber `https://filmber.online`.
3. Нажмите «Сохранить».

Без этого шага пользователь будет подключён, но события просмотра отправляться
не будут.

## 5. Проверьте работу

1. Запустите в Jellyfin фильм или эпизод с TMDB ID.
2. Посмотрите некоторое время или отметьте тайтл просмотренным.
3. Откройте Filmber и проверьте прогресс или статус просмотра.

События могут появиться не мгновенно. Если Filmber временно недоступен, плагин
сохранит их в локальной очереди и повторит отправку.

## Несколько пользователей

Повторите подключение для каждого пользователя Jellyfin. Связь и токен у
каждого пользователя отдельные.

## Обновление

Новые версии появляются в подключённом репозитории Jellyfin. Установите
обновление из каталога плагинов и перезапустите сервер.

Готовые ZIP-сборки также доступны в
[GitHub Releases](https://github.com/dmitrijovsjanik/filmber-jellyfin-plugin/releases).

## Если синхронизация не работает

Проверьте:

1. включена ли «Синхронизация» и нажата ли кнопка «Сохранить»;
2. подключён ли нужный пользователь Jellyfin;
3. не помечено ли подключение как истёкшее;
4. есть ли у фильма или сериала TMDB ID;
5. доступен ли `https://filmber.online` с сервера Jellyfin;
6. был ли Jellyfin перезапущен после установки или обновления.

Расширенная инструкция: [`docs/installation.md`](docs/installation.md).
